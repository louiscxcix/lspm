SIN LOTE / MES · Operational guide
Risk management · Guía de respuesta

¿Qué hacer cuando aparece SIN LOTE?

Guía para identificar la incidencia, contener el riesgo y escalar la corrección. Compara siempre el producto físico con el registro MES. Esta guía no sustituye el procedimiento autorizado.

Regla principal: No inventes un LOT ni avances el producto para hacer coincidir la pantalla. Primero compara el estado físico con el historial MES.
01 · Process Map

Identifica antes de actuar

Selecciona un caso para ver el procedimiento.
1. Detener y contener

Identifica pieza, array, bandeja y estación. Evita que avance sin trazabilidad.

2. Comparar físico vs. MES

Revisa LOT, QR, estación real y última operación registrada.

3. Clasificar la incidencia

LOT existe, LOT no existe o el proceso físico no coincide con el historial.

¿Qué situación describe el caso?
Case 01

LOT generado, historial posiblemente incorrecto

VERIFICAR HISTORIAL
1
Confirma el LOT y el QR

Verifica que el LOT corresponda al producto físico y que el código pueda leerse.

2
Compara la última operación

Contrasta la estación real con la última operación registrada en MES.

3
Contén y escala

Si hay diferencia, retén el producto y avisa al responsable de Producción/MES.

4
Reanuda solo con autorización

Continúa cuando el historial se haya corregido mediante el proceso autorizado.

Resultado esperado: LOT identificado, historial verificado y diferencia documentada. No crees un segundo LOT como solución improvisada.
Case 02

LOT no generado

NO CREAR SIN VALIDAR
1
Detén el avance del material

Identifica y separa el producto para evitar mezclarlo con material trazable.

2
Confirma array y etiquetas

Cuenta las posiciones presentes y verifica QR, modelo y condición física.

3
Revisa la regla de generación

Confirma el requisito de array completo y la secuencia aprobada para LOT parcial.

4
Solicita la recuperación aprobada

Espera instrucciones de Producción/MES antes de crear LOT o ejecutar Router.

Pendiente de confirmar: La secuencia exacta para arrays parciales (por ejemplo, 2–5 posiciones) no está confirmada. No improvisar el orden de Router, LOT individual o QR representativo.
Case 03

Proceso físico diferente del historial MES

CONTENER Y CORREGIR
1
Confirma la posición física

Identifica la operación real del producto; no te bases solo en la pantalla.

2
Compara el historial

Revisa LOT/QR, estación, operación registrada y registros disponibles.

3
Retén y notifica

No avances, repitas la operación ni cambies manualmente el estado para forzar coincidencia.

4
Corrige por el procedimiento autorizado

El responsable define cómo reconciliar MES con la condición física y confirma el siguiente proceso.

Importante: Si MES muestra Router, pero el producto ya avanzó físicamente, verifica la condición real y solicita la corrección autorizada. No asumas que hay que sustituir una máquina.
02 · MES RECOVERY

Resolución en MES · paso a paso

Selecciona la rama correspondiente al estado real del LOT y sigue el flujo de corrección.

Antes de modificar MES: identifica la pieza/array, confirma el QR y compara el estado físico con el historial. No cambies registros para “hacer que coincidan” sin confirmar el proceso real y la autorización requerida.
RAMA A · LOT NO GENERADO

Crear y relacionar LOT según el tipo de array

MES · LOT
1
Entrar al módulo de generación de LOT en MES

Busca la función autorizada para crear LOT. La ubicación exacta del menú, los nombres de campos y los permisos dependen de la configuración local; esta guía no inventa nombres de pantallas.

2
Verificar si están las 6 posiciones del array

Confirma la cantidad física y que cada pieza/posición y QR correspondan al modelo y array que se está procesando.

3A
Si las 6 están completas: usar el flujo normal

Según la explicación de la planta, cuando las seis posiciones/LOT están disponibles se sigue el flujo normal de generación del representante del array. Antes de confirmar, valida que el array y los LOT correspondan.

3B
Si solo hay 2–5: no forzar el flujo de array completo

La explicación indica que se deben recuperar/gestionar los LOT individuales y después pasar por Router para crear el LOT representativo. El orden exacto de cada pantalla y transacción todavía debe validarse con el responsable del proceso.

4
Crear el QR del LOT representativo

En el flujo descrito, el QR del LOT representativo se genera directamente. Verifica que el QR creado corresponda al array/representante correcto antes de usarlo.

5
Completar el flujo y verificar la relación

Después de completar el flujo indicado, verifica en MES el LOT representativo, los LOT individuales relacionados, el número de piezas y el historial. La explicación indica que al completar el representante, este se divide/relaciona de nuevo con los LOT individuales.

Confirmación obligatoria: el tratamiento de arrays parciales (2–5 posiciones), la secuencia exacta de transacciones y quién autoriza la creación/relación deben confirmarse con el dueño del proceso. No ejecutar una secuencia inferida en producción.
RAMA B · LOT EXISTE, PERO EL HISTORIAL ESTÁ ATRÁS

Ejemplo: MES muestra Router, pero la pieza ya avanzó

MES · HISTORIAL
1
Consultar el LOT existente

Busca el LOT en MES y confirma su identidad mediante el QR/identificador y el modelo. No crees otro LOT solo porque la operación mostrada sea incorrecta.

2
Confirmar la última operación registrada

Revisa el historial/transacciones del LOT. En el ejemplo descrito, MES solo refleja Router.

3
Determinar la operación física real

Confirma con el producto y el responsable de línea hasta qué operación llegó realmente. No deduzcas el punto de reanudación solo desde MES.

4
Usar el flujo de representante si corresponde al caso

La explicación indica que este caso puede requerir crear el LOT representativo, escanearlo y generar/relacionar los LOT individuales; después, enviar el producto al proceso correspondiente. Esta rama debe ser validada por el responsable para confirmar cuándo aplica y en qué orden.

5
Corregir el historial por la función MES autorizada

Si se necesita retroceder/ajustar el estado (“back”) en MES, debe hacerlo la persona autorizada siguiendo el procedimiento local. No se especificó el nombre de la función, qué transacción se revierte ni qué permisos aplican.

6
Confirmar el punto correcto de continuación

Compara de nuevo estado físico, LOT/QR y MES. Reanuda desde la operación definida por el responsable, evitando repetir una operación ya completada o saltarse una pendiente.

Principio clave: el objetivo no es cambiar la pantalla para que parezca correcta; es reconciliar el historial MES con el trabajo realmente ejecutado y preservar la trazabilidad.
RAMA C · PROCESO EQUIVOCADO

El producto está en una operación que no coincide con MES

MES · RECONCILIACIÓN
1
Identificar el punto físico real

Registrar qué proceso se completó realmente y qué operación está pendiente. Usar evidencia disponible y confirmación del responsable.

2
Comparar contra el historial MES

Revisar LOT/QR, operaciones registradas y la última transacción válida. Distinguir entre historial atrasado y una operación realmente omitida.

3
Solicitar corrección / back autorizado

El responsable MES/Producción determina si corresponde retroceder, corregir una transacción o relacionar LOT. No inventar un número de operación ni modificar el historial manualmente.

4
Verificar antes de devolver a línea

El estado MES debe representar fielmente lo ejecutado y el responsable debe definir el proceso de reanudación. No asumir que se requiere reemplazar una máquina.

No continuar si no se puede demostrar qué operación está completada, si el LOT/QR no coincide o si falta la autorización para corregir MES.

Datos que deben quedar registrados en cada recuperación

LOT / QR afectado
Identificador del LOT, LOT representativo e individuales relacionados, si aplica.
Estado antes de corregir
Última operación MES y operación física real.
Acción realizada en MES
Transacción/corrección aprobada y persona autorizada.
Validación posterior
Relación de LOT, cantidad de piezas, historial actualizado y punto de reanudación aprobado.
MES 수정 전: 대상 제품/어레이를 식별하고 QR을 확인한 뒤, 실물 상태와 MES 이력을 비교하세요. 실제 공정과 권한을 확인하지 않은 채 화면을 맞추기 위한 기록 변경을 해서는 안 됩니다.
분기 A · LOT 미생성

어레이 상태에 따라 LOT 생성 및 연결

MES · LOT
1
MES의 LOT 생성 메뉴 진입

권한이 부여된 LOT 생성 기능을 찾습니다. 메뉴 위치, 필드명, 권한은 현장 시스템 설정에 따라 다르므로 이 가이드에서 확인되지 않은 화면명을 임의로 만들지 않습니다.

2
어레이 6개 위치가 모두 준비됐는지 확인

실제 수량을 확인하고 각 제품/위치의 QR, 모델, 어레이가 대상과 일치하는지 확인합니다.

3A
6개가 모두 준비된 경우: 정상 흐름 사용

현장 설명상 6개 위치/LOT가 모두 준비되면 정상적인 대표 LOT 생성 흐름을 사용합니다. 확정 전에 어레이와 각 LOT가 맞는지 검증합니다.

3B
2~5개만 있는 경우: 전체 어레이 흐름을 강제로 사용하지 않음

설명에 따르면 개별 LOT를 살리거나 관리한 뒤 Router를 거쳐 대표 LOT를 만드는 예외 흐름입니다. 각 MES 화면과 트랜잭션의 정확한 순서는 공정 책임자에게 확인해야 합니다.

4
대표 LOT의 QR 직접 생성

설명된 흐름에서는 대표 LOT의 QR을 직접 생성합니다. 생성한 QR이 올바른 어레이/대표 LOT에 해당하는지 확인한 후 사용합니다.

5
흐름 완료 후 LOT 관계 검증

처리 완료 후 MES에서 대표 LOT, 연결된 개별 LOT, 제품 수량, 공정 이력을 확인합니다. 설명상 대표 LOT 완공 후 다시 개별 LOT로 분리/연결되는 구조입니다.

반드시 확인: 부분 어레이(2~5개)의 처리 방식, 정확한 트랜잭션 순서, 생성/연결 승인자는 공정 책임자에게 확인해야 합니다. 추정한 순서를 실생산에서 실행하지 마세요.
분기 B · LOT는 있으나 이력이 뒤처짐

예: MES에는 Router만 있고 실물은 후속 공정까지 진행됨

MES · 이력
1
기존 LOT 조회

MES에서 LOT를 조회하고 QR/식별자와 모델로 실물 제품과 일치하는지 확인합니다. 표시된 공정이 잘못됐다는 이유만으로 새 LOT를 만들지 않습니다.

2
마지막 등록 공정 확인

LOT의 이력/트랜잭션을 확인합니다. 예시에서는 MES에 Router까지만 기록돼 있습니다.

3
실제 완료 공정 확인

제품 실물과 라인 담당자를 통해 실제로 어디까지 진행됐는지 확인합니다. MES 화면만 보고 재개 지점을 추정하지 않습니다.

4
해당 사례에 대표 LOT 흐름이 필요한지 확인

설명상 대표 LOT 생성, 스캔, 개별 LOT 생성/연결 후 해당 공정으로 보내는 방식이 필요할 수 있습니다. 적용 조건과 순서는 담당자가 확인해야 합니다.

5
승인된 MES 기능으로 이력 수정

MES에서 상태를 되돌리거나(back) 조정해야 한다면 권한자가 현장 절차에 따라 수행합니다. 기능명, 되돌릴 트랜잭션, 필요한 권한은 아직 제공된 설명에서 확정되지 않았습니다.

6
올바른 재개 지점 확인

실물 상태, LOT/QR, MES를 다시 비교합니다. 이미 완료한 공정을 반복하거나 미완료 공정을 건너뛰지 않도록 담당자가 재개 지점을 승인해야 합니다.

핵심 원칙: 화면을 그럴듯하게 바꾸는 것이 목표가 아닙니다. 실제 작업 이력과 MES를 정합화하고 추적성을 유지하는 것이 목표입니다.
분기 C · 잘못된 공정

실제 제품 위치와 MES 공정이 다름

MES · 정합화
1
실제 공정 위치 파악

실제로 완료된 작업과 아직 남은 작업을 기록합니다. 확인 가능한 증거와 담당자 확인을 활용합니다.

2
MES 이력과 비교

LOT/QR, 등록 공정, 마지막 유효 트랜잭션을 확인합니다. 단순 이력 지연인지 실제 공정 누락인지 구분합니다.

3
승인된 수정 또는 back 요청

MES/생산 담당자가 공정 되돌리기, 트랜잭션 수정, LOT 연결 중 필요한 조치를 결정합니다. 공정 번호를 임의로 정하거나 이력을 수동으로 바꾸지 않습니다.

4
라인 복귀 전 검증

MES 상태가 실제 수행 작업을 정확히 반영하고, 담당자가 재개 공정을 지정했는지 확인합니다. 설비 교체가 필요하다고 단정하지 않습니다.

진행 금지: 완료 공정을 입증할 수 없거나, LOT/QR이 일치하지 않거나, MES 수정 권한 승인이 없다면 다음 공정으로 진행하지 않습니다.

MES 복구 시 남겨야 할 기록

대상 LOT / QR
LOT 식별자, 대표 LOT 및 연결된 개별 LOT(해당 시).
수정 전 상태
MES 마지막 공정과 실제 제품 공정.
MES에서 수행한 조치
승인된 트랜잭션/수정 내용과 수행 권한자.
수정 후 검증
LOT 관계, 수량, 갱신된 이력 및 승인된 재개 지점.
