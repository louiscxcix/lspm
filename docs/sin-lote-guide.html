SIN LOTE / MES mismatch response
Risk management · Guía de respuesta

¿Qué hacer cuando aparece SIN LOTE?

Guía de apoyo para identificar el tipo de incidencia, contener el riesgo y escalar la corrección. Compara siempre el producto físico con el registro MES. Esta guía no sustituye el procedimiento autorizado de producción ni la aprobación del responsable.

Regla principal: no inventar un LOT, no volver a ejecutar una operación y no mover el producto al siguiente proceso solo para hacer coincidir la pantalla. Primero confirma el estado físico y el historial MES; después solicita la corrección aprobada.
01 · Flujo general

Identifica antes de actuar

Selecciona una situación abajo para ver los pasos.
1. Detener y contener

Identifica la pieza, array, bandeja y estación. Evita que avance sin trazabilidad.

2. Comparar físico vs. MES

Revisa LOT, QR, estación real, última operación registrada y estado mostrado.

3. Clasificar la incidencia

LOT existe, LOT no existe o el proceso físico no coincide con el historial.

↓
¿Cuál de estas tres situaciones describe el caso?
Caso 01

LOT generado, historial posiblemente incorrecto

VERIFICAR HISTORIAL
1
Confirma el LOT y el QR

Verifica que el LOT corresponda al producto físico y que el código pueda leerse.

2
Compara la última operación

Contrasta la estación real con la última operación registrada en MES. No asumas que el LOT correcto significa historial correcto.

3
Contén y escala

Si hay diferencia, retén el producto y avisa al responsable de producción/MES para revisar el historial.

4
Reanuda solo con autorización

Continúa cuando el historial haya sido corregido por el proceso autorizado y el responsable confirme el siguiente paso.

Resultado esperado: LOT identificado, historial verificado y diferencia documentada. No crees un segundo LOT como solución improvisada.
Caso 02

LOT no generado

NO CREAR SIN VALIDAR
1
Detén el avance del material afectado

Separa/identifica el producto para evitar mezclarlo con material trazable.

2
Confirma array y etiquetas

Cuenta las posiciones/piezas presentes y verifica QR, modelo y condición física.

3
Revisa la regla de generación

Confirma con el responsable el requisito de array completo y la secuencia aprobada para LOT parcial.

4
Solicita la recuperación aprobada

Registra lo observado y espera instrucciones de Producción/MES antes de crear LOT o ejecutar Router.

Punto pendiente de confirmación: la secuencia exacta cuando el array contiene solo algunas posiciones (por ejemplo, 2–5) no está confirmada. No improvisar el orden de Router, LOT individual o QR representativo.
Caso 03

Proceso físico diferente del historial MES

CONTENER Y CORREGIR
1
Confirma la posición física

Identifica en qué operación está realmente el producto; no te bases solo en la pantalla.

2
Compara el historial completo

Revisa LOT/QR, estación anterior, operación registrada y cualquier registro disponible.

3
Retén y notifica

No avances, no repitas la operación ni cambies manualmente el estado para forzar una coincidencia.

4
Corrige por el procedimiento autorizado

El responsable debe definir cómo reconciliar MES con la condición física y confirmar desde qué proceso puede continuar el producto.

Importante: si MES muestra Router, pero el producto físico ya avanzó a una operación posterior, primero verifica la condición real y solicita la corrección aprobada. No se debe asumir que hay que sustituir una máquina.
02 · Registro de control

Checklist antes de liberar el material

Marca cada punto una vez confirmado. El progreso es local a esta página y no se guarda en MES.

0 de 6
Regla de liberación: no marcar el caso como resuelto solo porque aparece un LOT en pantalla. Debe confirmarse la correspondencia entre producto físico, trazabilidad MES y autorización de continuación.
Estado de esta guía: borrador operativo. Los criterios de recuperación para array parcial, las personas autorizadas para modificar MES y el criterio formal de liberación deben confirmarse con el dueño del proceso antes de usarla como instrucción oficial. No reemplaza el procedimiento aprobado de la planta.
