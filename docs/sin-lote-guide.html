Guía para recuperar material acumulado SIN LOTE

Esta guía es para material que ya quedó apartado o acumulado por un problema SIN LOTE. No es una instrucción para detener la línea ni un checklist de prevención. El objetivo es recuperar la identificación, corregir el registro MES cuando corresponda y devolver cada unidad al flujo correcto.

REGLA OBLIGATORIA PARA TODOS LOS CASOS

Después de recuperar el LOT/QR y corregir/confirmar el registro MES, todo material recuperado que vuelva a la línea debe reiniciar su recorrido desde EOL. No lo reincorpores directamente a una estación intermedia. Confirma el procedimiento de entrada por EOL y completa las operaciones requeridas desde ese punto.

Primero: identifica qué le falta al material

Selecciona el caso que describe el estado actual del producto. El procedimiento cambia según exista LOT, QR y un historial MES coherente.

CASO 01 · CREACIÓN / RECUPERACIÓN DE LOT

Resolver material sin LOT

Usa esta ruta cuando el material acumulado no tiene un LOT/QR que permita continuar su trazabilidad. Primero determina si el array está completo o parcial.

1

Agrupa el material por modelo y array

Reúne las unidades que pertenecen al mismo modelo y al mismo array. No mezcles unidades de modelos o lotes distintos. Cuenta las unidades físicas y anota cuántas están presentes.

2

Define si el array está completo o parcial

La referencia operativa disponible describe arrays de 6 unidades. Si están las 6, sigue el flujo normal aprobado para el array. Si solo hay de 2 a 5, trata el caso como array parcial y confirma el orden de recuperación con el responsable antes de registrar datos en MES.

Ruta A · Array completo (6/6)

  1. Confirma el modelo y que las seis unidades pertenezcan al mismo array.
  2. Localiza el flujo normal aprobado de creación/registro del LOT para esa línea.
  3. Crea o registra el LOT únicamente mediante esa transacción autorizada.
  4. Genera o imprime el QR correspondiente y comprueba que identifica el LOT correcto.

Ruta B · Array parcial (2–5)

  1. Registra cuántas unidades quedan y confirma la ubicación de las unidades faltantes.
  2. Confirma con el responsable si se requiere gestionar LOT individuales y un LOT representativo.
  3. La secuencia de referencia menciona Router, creación del LOT representativo y QR directo, finalización del representativo y relación con los LOT individuales. Confirma el orden exacto antes de ejecutar.
  4. No inventes IDs ni relaciones para compensar unidades faltantes.
3

Genera el QR con la herramienta de Louis

Abre la herramienta, introduce el contenido/identificador que ya fue confirmado para este caso, genera el QR y escanéalo para verificar que el valor leído coincide exactamente. No inventes el formato ni reutilices el QR de otro producto.

4

Registra el LOT y establece las relaciones en MES

El QR es solo la etiqueta legible. Después de generarlo, completa por separado las operaciones autorizadas de MES: registro del LOT, finalización del LOT representativo si aplica y asociación con los LOT individuales. Reabre la consulta del LOT para confirmar que las relaciones quedaron guardadas.

5

Devuelve el material al proceso que corresponde

Con LOT/QR identificable y relaciones verificadas, confirma cuál es el siguiente proceso permitido para ese material. Colócalo en el flujo de ese proceso; no lo envíes automáticamente a Router si el estado real y la ruta aprobada indican otro punto.

Resultado esperado

Cada unidad puede identificarse; el QR corresponde al identificador confirmado; las relaciones LOT están registradas en MES y el material vuelve al proceso correcto.

CASO 02 · LOT EXISTENTE

LOT existe, pero MES se quedó en Router

Aquí no se empieza creando otro LOT. Se recupera la trazabilidad del LOT existente y se determina qué proceso debe aparecer como siguiente.

1

Lee el QR y abre la consulta del LOT existente

Utiliza el identificador físico para consultar el LOT. Confirma modelo, producto/array y cantidad para evitar trabajar sobre otro registro.

2

Anota el último proceso registrado y el real

Ejemplo: MES muestra Router, pero el material ya está en una estación posterior. Anota el proceso que muestra MES y el proceso que realmente completó el producto. Confirma la operación con el operador o el registro disponible.

3

Decide si falta una transacción o si aplica LOT representativo

No asumas que todo caso Router requiere un nuevo LOT representativo. Comprueba si el producto pertenece a un array parcial o a un flujo con LOT representativo. Si ya existe LOT válido, prioriza recuperar el registro existente según el método aprobado.

4

Aplica la transacción de recuperación autorizada

Con el responsable MES, determina si se debe completar un registro pendiente, corregir la asociación o utilizar una función autorizada de ajuste/retroceso. Ejecuta solo la opción que corresponda al estado real. No repitas la operación física para arreglar el historial.

5

Vuelve a consultar el LOT y libera el material

Comprueba que el historial actualizado refleje la secuencia real, que no se haya creado un LOT duplicado y que el siguiente proceso sea el correcto. Registra quién confirmó la recuperación y devuelve el material al flujo aprobado.

CASO 03 · RUTA INCORRECTA

Corregir proceso incorrecto en MES

1

Identifica el punto exacto de la diferencia

Consulta la ruta MES del LOT y reconstruye la secuencia física con la información de producción. Define el último paso que coincide y el primer paso que difiere.

2

Determina qué ocurrió realmente

Distingue entre operación realizada pero no registrada, registro realizado en el proceso equivocado y operación física omitida. Son situaciones diferentes y no deben corregirse con la misma acción automáticamente.

3

Selecciona la recuperación correcta con el responsable

Si la operación se realizó y solo falta el registro, confirma cómo registrar la evidencia. Si se registró el proceso equivocado, confirma el método autorizado de corrección. Si la operación física se omitió, el responsable de proceso debe decidir cómo recuperar la ruta; no marques una operación no realizada como terminada.

4

Corrige y vuelve a comprobar la ruta

Aplica el método autorizado y vuelve a abrir el historial. Confirma que el proceso real y el registrado coincidan y que el siguiente proceso habilitado sea correcto.

5

Registra el resultado y devuelve el material

Anota la causa, la corrección aplicada y quién la validó. Devuelve el material al punto del flujo que corresponde a su estado físico confirmado.

Cierre de recuperación: qué debe quedar resuelto

Identificación

Cada unidad o array se identifica con el LOT/QR correcto; no hay duplicados ni relaciones cruzadas.

Estado MES

El historial coincide con la operación física confirmada y la ruta indica el siguiente proceso correcto.

Trazabilidad

Si existe LOT representativo, su relación con los LOT individuales está guardada y puede consultarse.

Retorno al flujo

El material acumulado vuelve al punto correcto del proceso y queda documentado quién validó la recuperación.

Nota de precisión

La guía detalla el flujo operativo conocido, pero los nombres exactos de pantallas, botones y transacciones MES —y el orden obligatorio para arrays parciales— deben confirmarse con capturas reales y el responsable del proceso. No se deben adivinar.
